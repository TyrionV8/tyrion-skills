# Capturar evidência com Remotion

Use quando o usuário invocar `$capturar-evidencia-remotion`. Como primeira etapa,
carregue e siga [capturar-evidencia](../capturar-evidencia/SKILL.md). Ela define
como obter ou reutilizar a captura, tratar o ambiente e as permissões e registrar
o comportamento observado. Prepare o material de base uma vez e use-o nesta
montagem. Um pedido de anotação de mídia existente pode ser atendido com o
material fornecido.

## Aplicar marcações

Siga o formato pedido. Quando o pedido deixar o formato em aberto, preserve o
formato do material existente ou use GIF para uma nova captura.

- **GIF animado** (Graphics Interchange Format). Use Remotion para sincronizar as
  marcações com a ação e o resultado. Posicione a ponta do ponteiro no centro
  da região clicável do controle
  ao clicar. Mantenha-a parada e visível até o momento da próxima ação. Comece
  a mover o ponteiro só quando o próximo alvo estiver visível.
- **Capturas individuais ou reunidas.** Use Remotion para renderizar quadros
  estáticos com as indicações. Respeite a ordem e o agrupamento escolhidos.
- Escolha marcações que ajudem a ver o comportamento. Use texto curto no topo
  para indicar a etapa atual. Quando houver marcos verificáveis, mostre a etapa
  atual na sequência. Use setas para apontar o controle, contornos para
  identificar o detalhe exato ou escureça o entorno para que a área relevante
  permaneça clara. Aproxime só quando o detalhe precisar de ampliação para
  ficar legível. Preserve mensagens, rótulos e estados, inclusive os inesperados.

Leia [Montar e verificar com Remotion](references/montar-no-remotion.md) para
preparar a composição, sincronizar o ponteiro e validar a saída.

Exemplo de invocação. “Use `$capturar-evidencia-remotion` para tentar salvar este
cadastro na aplicação local. Destaque o clique e a mensagem que aparecer.”
